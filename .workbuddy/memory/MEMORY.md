## 逆向方法论（必守·核心坑）
- 映像 `scripts/_unpacked_mem.bin`(2MB,base 0x400000,OEP 0x4f44b0)；⚠️ **`_insn_addrs.pkl` 有空洞**（实测 `0x49b417..0x49b43a` 缺 10 条指令，从 `0x49b416` 直跳 `0x49b440`），基于它的断言会**静默假失败**。**关键处一律用 `_lindis.py` 或 capstone 现场反汇编核对。**；函数边界=「所有 call rel32 目标」。工具 `_fdis.py`/`_lindis.py`/`_emu_*.py`(Unicorn 2.1.4)；capstone `from capstone.x86 import *`。
- 🔑 禁止猜表形状，必须穷举（串池扫描）；数据须读原始 DAT（JSON 转储会丢信息）。
- 🔑 立即数 xref 按「指令包含」判定；扫基址须连扫 base±1..±4。
- 🔑 定 stride 三证据：① lea 系数 ② 乘减序列 ③ 除法魔数（÷14=`0x92492493`+sar3、÷10=`0x66666667`+sar2、÷12=`0x2aaaaaab`+sar1、÷31=`0x84210843`+sar4、÷47=`0xae4c415d`）。
- 🔑 **switch 惯用法（续129）**：`cmp`+`ja` → byte 转码表 → dword 跳表（差=4×项数）。
- 🔑 两套武将编号勿混：实体 `0x519868` stride47×370 ≠ BSDATA 700。定名优先「反向查表」(`msgx_all_texts.json`)。
- 🔑 **「先猜常数、后反查立即数」（续131）**：先猜常数(如生年1490=`0x5d2`)再全镜像扫描。
- 🔑 **BSDATA↔实体 -12 通则（续135）**：`entity[i]=bsdata[i+12]`，适用 `@22..@55`。
- 🔴 **「静态抓不到写入」≠ 须 emu（续132 纠偏）**：常因 setter 按 `ecx=base+N` 参数化传入偏移，绝对偏移从不出现。排查：找同名 setter 族 → 抓 e8 调用方看 ecx 来源 → 用调用点 `lea/add ecx,N` 反推真实偏移。
- 🔴 **「是否被写入」须下探实参传递（续139）**：只扫字面 `mov ecx,<base>` 会漏 `push <base>; call helper`（helper 内 `esi=[esp+0xc]; ecx=esi`）。**顺序：① 字面 ecx ② 沿 call 下探一层找「取实参作 this」③ 才下结论。**
- 🔴 **「位移命中」≠「字段命中」（续143，第 6 次多 struct 陷阱）**：扫 `word[reg+0x2a]`/`[reg-2]` 会命中 S5(`0x5197bc`/`0x5197ba`)、表 `0x510b54`/`0x525356`、栈局部 `[esp+0x28]`、`add esi,2` 数组轮转、`add edx,4` 排序交换。**判定必须先溯源基址寄存器**（`esi=0x519868` / 迭代基点 `0x519894` / ÷47 魔数 / 计数 370 或 359）。实例：100 命中 → 14 疑似写点 → 溯源后 **10 个全是误报**，唯一真写入路径是 setter。
- 🔴 **「函数内含某表基址」≠「该访问属于那张表」（续145 加严）**：`sub eax,0x51eb88`+÷31 可能是**把城指针换算成城索引**再写进别的结构体（`0x4baff0@0x4bb23e` 写的是 S6 ctx `+8`）。判定写点必须精确到「**写目标寄存器本身**被 `mov/add reg,<表基址>` 赋值」，不能只看函数里出现过基址。
- 🔑 **结构填充的成对指纹（续145）**：`mov word[reg+0xa],X` 紧跟 `mov word[reg+8],X`（各 4 字节、同寄存器、同值）⇒ 是**结构体 word 批量初始化**，不是字段写入。全镜像 9 处该形态全部指向 S6 ctx。
- 🔑 **表基址/记录起点必须打分裁决（续145）**：对候选偏移用「N 条记录 × 多个结构锚点」同时打分（如城表：城主<370 / `[19:21]==0xffff` / 所属国≤48 / 城種&7），真值四项全绿、伪像会崩。可一次性终结基址争议。

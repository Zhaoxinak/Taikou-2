### 突破（全部逐指令验证）
1. **`0x4ebfc0`=strlen / `0x4ebfe0`=strcpy**：`0x4ebfc0` = `test ecx,ecx` 空指针返0 → `mov dl,[ecx]` 逐字节 `test dl,dl` + `inc eax`；`0x4ebfe0` = `mov esi,[esp+0xc]`(src) + `mov eax,edx`(返 dst) → `mov [edx],cl` 循环 → `mov byte[edx],0`。⇒ **推翻续158「块拷贝助手」**，且**无 size 参数**（续158「仍未知② size 来源」前提不成立）。

## 续162 · SNDATA「payload 解析引擎」实为资源加载管线（承接续161 下一步 A）

- **资源读取走文件 I/O**：`0x441330`/`0x441360` 经 `call dword ptr [0x4fb0a8]`（同 read_record 派发；`0x441360` 经 `mov edi,[0x4fb0a8]; call edi` 间接）+ `call 0x441170` 写游戏表 `0x524978`/`0x524918`；失败路径 `0x47bde0`=`push 0x5094d0`+`call 0x47ae80`（记「资源未找到」日志）。

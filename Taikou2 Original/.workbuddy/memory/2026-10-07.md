```

```
⇒ 写 1024B 进 370B 栈数组 → 踩穿返回地址 → **EIP=0**（正是最初那个崩溃的形态）

目标是 **`lea r,[esp+n]` = 栈数组 ⇒ 绝不能放大**（0x49C5E5、0x49CD3D）；
其余 3 处目标为全局/堆数组（池 0x53C000 CAP*47、姓名两表 CAP*7 在 P3 已同步放大）⇒ 缩放是对的。

### ★★★★ 过日子崩溃根因坐实：日志桩调用约定不一致（多清栈）→ ESP 漂移 → ret 到 0
**探针夹逼（`--probe 0x54CA00,0x54CA05,0x54CA0A,0x4A4CC5`）一次定性：**
```
命中 0x4A4CC5 ✓  →  命中 0x54CA00(child_pass 入口) ✓  →  命中 0x54CA05(child_growth_pass 入口) ✓
→  0x54CA0A(popal) 未命中 ✗
```
⇒ **崩在 `child_growth_pass`(0x54CA20) 内部**；而该桩内**没有任何间接转移**
（全范围扫 `call/jmp dword ptr` 为 0）⇒ 只能是它**调用的函数改了栈**。

**根因**：日志桩 `0x54C988`（写 `C:\taikou_debug.log`，`CreateFileA`/`_lwrite`/`_lclose`）

```
0x54CA2F push 0x43 → 后接 mov ebx       ✓      0x54C80C/0x54C97E 也 ✓
0x54CA9B push 0x44 → 后接 add esp,4     ✗      0x54CDB6 push 0x45 → add esp,4  ✗
0x54CE6C push 0x46 → 后接 add esp,4     ✗
```
`0x54CAA0` 那条**每结算一个孩子走一次**（`GROWTH_SETTLED=14` ⇒ +56B）；
实测崩溃时 ESP 比桩入口高 **0x40=64B** ⇒ 数字对得上。
ESP 漂到返回地址之外 → 弹栈拿到垃圾（`EBP=0x530006`）→ 最终 `ret` 弹到 0 → **EIP=0**。

栈回溯全在游戏菜单链（`0x4CE785 call 0x4CD320` …），崩点其实是 **jmp 进来的** MENU_SCR 桩
（菜单钩 `0x4CD563: jmp 0x550F00`），所以栈上找不到 MOD 内返回地址。

根因（`child_menu.py` 的 `cm_same` 块）：**edi 一身兼两职**
```
mov edi, [esp+0x0C]          ; edi = row 行号 (0..page_max-1)
lea edx,[edi+edi*2]; shl edx,3; add edx, name_buf   ; edx = name_buf + row*24
mov [edi*4 + sub_ptr], edx   ; edi 当索引 ✓
mov [edi*2 + slot_arr], ax   ; edi 当索引 ✓
...
mov byte ptr [edi], al       ; edi 当写指针 ✗  row=0 ⇒ 写地址 0
```
`edx` 已算好本行缓冲却没人拿它当游标。修法（等长替换，后续代码零位移）：
```
0x5510BA  89 C6    mov esi,eax  -> 89 D7      mov edi,edx
0x5510BC  C1E603   shl esi,3    -> 6B F0 07   imul esi,eax,7   (shl3+sub ≡ *7)
0x5510BF  29 C6    sub esi,eax  -> 90 90      nop nop
```
`mk_fix3.py` = fix1(A/B) + fix2(C) + 本组(D)，与 big.exe 差 **39 字节 / 11 处**。
源码 `child_menu.py` 已同步（在 275 行后补 `mov edi, edx`，保留 shl/sub 两步以免 keystone 语法风险）。

**通用教训**：MOD 桩里一个寄存器别同时当"索引"和"指针"；写字符串拷贝循环前先确认游标初值。
崩点若在 `[MOD+0x...]` 且栈回溯只有游戏代码 ⇒ 是 `jmp` 进来的桩，别在游戏代码里找。

### ★★ bug 1：日期狂奔 —— `0x4A0D50` 是 cdecl，我把调用约定记反了
之前在摘要里写成「stdcall 自清 8B」，**错了**。证据（全镜像 79 个调用点，字节级 E8 扫描）：

```
0x4B4075 push 1 ; push 0x18 ; call 0x4A0D50 ; add esp,8     <- 绝大多数原生长这样
0x4CDBCF push edi; push 0x18; call 0x4A0D50 ; add esp,8
0x490D94 push 1 ; push 2    ; call 0x4A0D50 ; add esp,8
```

而我的推天数循环漏了 `add esp,8`：

```
cm_day_l: push ecx / push 1 / push 0x18 / call 0x4A0D50 / pop ecx / dec ecx / jne
```

`call` 返回后那两枚实参还在栈上，`pop ecx` 每次捡回的其实是残留实参 `0x18(=24)`，
于是 **ecx 每轮都被重置成 23，循环永不结束**，日期一路推进；还每轮漏 8B 栈。这就是"停不下来"。

**修**（`child_menu.SRC_FOSTER`）：
```
        test ecx, ecx
        je cm_day_done          # 0 天不进循环 (防 dec 绕回 4G 次)
cm_day_l:
        push ecx                # callee 不保 ecx
        push 1
        push 0x18
        call 0x4A0D50
        add esp, 0x8            # ★ cdecl: 调用方清两枚实参
        pop ecx
        dec ecx
        jne cm_day_l
cm_day_done:
```

## (03:25–03:40) 实机反馈修「培养后界面怎么乱了」 —— 串池格式不匹配 + 居中公式错

### 用户反馈
> 「培养后，界面怎么乱了？」
截图症状：黑框居中出现了、标题「森长可」在框**左外侧**、框内全黑没字、
屏幕底部横着两串跨行糊字（「…马屋打工挣到钱了铁炮的声音真响」「习礼法：3天/6金 茶道：4天/8金 学算术：3天/6金」）。

### ★ bug 1（主因）：串池是 `[GBK][NUL][pad]`，解码却按 `[长度][GBK]` 来
`.rev/child_menu.py::msg_str_pool_bytes()` 写的是
```python
out += b + b'\x00' * (MS_STR_ROW - len(b))     # 无长度前缀
```
而 `.rev/kid_panel.py::kd_m_frame` 照抄了 kid_panel 自己那套池的解码：
```
mov ecx, dword ptr [eax] / and ecx, 0xff / push ecx / inc eax / push eax
```
于是**汉字高字节被当成长度**：行 11「打工挣到钱了」首字节 0xb4=180 → TextOut 一口气画 180 字节
≈ 连画 7~8 行串池；提示行「点击关闭」首字节 0xb5=181 → 又是 181 字节。
屏幕底部那两串糊字就是这么来的（内容恰好横跨 行11..18 与 行15..22）。

**判据**（用产物字节直接看，不靠推理）：
```
0 off=  0  raw=d5e2b8f6d4c2d2d1beadc5e0d1f8b9fdc1cb0000   <- "这个月已经培养过了"+NUL+pad
11 off=264 raw=b4f2b9a4d5f5b5bdc7aec1cb0000...            <- 首字节 0xb4 = 汉字高字节
19 off=456 raw=cfb0c0f1b7a8a3ba33ccec2f36bdf0...          <- "习礼法：3天/6金"
```
**修**：两行改成 `push -1`（cbString = -1，GDI 自己找到 NUL）—— 因为池天生是 NUL 结尾的。

**为什么另一套池没事**：详情面板走的是**指针数组**（`KD_STRTAB`），由构建期填各条串的真实地址，
且 kid_panel 的池是 `[len][GBK][NUL]` **紧凑**排列，与它的 `movzx ecx,[eax]; inc eax` 解码配套。
**两套池格式不同，不能互相抄解码** —— 已写进 kid_panel.SRC_ALL 顶部注释。

**为什么串池不能加长度前缀**：`cost_arr` / `deny_*_ptr` 要直接喂给原生对话框 `0x47BED0`，
它收的是 C 字符串指针；串首塞长度字节会被它当第一个字符显示成乱码。

### ★ bug 2：居中写成 `(wx0 + MW)/2` 而不是 `(wx0 + wx1)/2`
`kd_frame`（详情面板）写的是对的：
```
mov eax, [r_wx0] / add eax, dword ptr [r_wx1] / sar eax, 1
```
`kd_m_frame`（反馈小框）三处全写成了：
```
mov eax, [r_wx0] / add eax, 0x1cc(=MW) / sar eax, 1
```
⇒ 客户区宽 1280、wx0=410 时，正确中心是 639，实际算出 435 —— **偏左 200px，整行文字跑到黑框左外侧**，
所以框内空空、标题却在框外。**修**：三处统一改成 `add eax, dword ptr [r_wx1]`。

### ★ bug 3（自查拦下，没进产品）：槽守卫不能随手写小
我顺手加的越界守卫原本写 `cmp [msg_slot], 0x40`。但孩子实体实际在**槽 463..476**
（`CHILD-PRELOAD: 批次 fam13 = 14 人 (槽 463..476)`），而姓名表是**按槽直索引**的（4578B / 7B = 654 行）。
写成 0x40 会让 kd_msg 头两行就 `jae` 走人 ⇒ **反馈框永远不弹**，而且症状是"什么都没发生"，比乱码更难查。
**修**：`NAME_TAB_ROWS = 654` / `SLOT_MAX_MSG = NAME_TAB_ROWS`，并加断言钉死。

### 顺带把货币单位核准了
截图「所持金 0贯200文」说明 `word[0x51662E]` 的单位是**文**（1 贯 = 1000 文），不是贯。
`GOLD_PER_DAY = 2` 是**照抄原生修行口径**（PLAN §0.2「每日 2 金」，字段同源），数值不动，
只把提示文案从 `…天/…金` 改成 `…天/…文`，拒绝框「银两不够」改成「所持金不足」（与游戏 UI 用词一致）。

### 新增防御
- `kid_panel.selfcheck_panel`：`and ecx,0xff` 命中数必须为 **0**；`push -1` 恰 **2**；

### 教训
1. **"屏幕上出现不该有的文字" = 指针/长度算错，不是绘制错**。先去数那个串指针指向哪、

2. **同一个 exe 里可以有两套串池格式**。抄解码逻辑前先确认格式（有没有长度前缀、紧凑还是 pad）。

## 续：实机第二轮 —— 三个 bug 一起修（空名单 / 大名对话抢先 / 反馈框空空如也）

### ① 进城→回家后名单空，要等下个月 —— `place_child` 只在月钩同步
- 名单按「孩子 `word[+0x24]` == 主角 `word[+0x24]`」筛，孩子随父居住的 `place_child` 只有两个调用点：
  `make_child` 末尾 + `child_pass` 的**月钩 `rearm`**。主角一移动，孩子还挂旧城 ⇒ 名单空到下次月钩。
- 修：`cm_foster` 开头（`0x550FE8`）**复跑一次 `child_pass @0x54C800`**。该桩入口 `push ebx/esi/edi/ebp`、
  `done` 处原样 pop，**无实参 / 幂等 / 自包含**，其 `rearm` 路径末尾正好调 `place_child`。
- 通法：**惰性（月钩）同步的数据被 UI 直接读 ⇒ 在读之前主动跑一次那个幂等刷新桩**，不要抄一份进 UI。

### ② 大名对话抢在孩子台词前面 —— `0x4A0D50` 的副作用
- 原顺序 `PAY → 0x4A0D50(推天数) → … → kd_msg`。**`0x4A0D50` 不只推天数，它会派发游戏原生每日事件**
  （使者来访 / 大名传话），这些对话抢占前景。
- 修：`kd_msg` 提到推天数之前。现 `PAY @0x5513D6 → kd_msg @0x5513D7 → ADVANCE_DAY @0x55140C`。
- 通法：**调用原生引擎函数的副作用要当成 API 的一部分记进注释**（不止"它做什么"，还有"它顺带触发什么"）。

### ③ 反馈框空空如也 —— 同一个 `cbString = -1` 坑第二次踩
- 上一轮为修糊字把 TextOutA 的 `cbString` 改成 `-1`；**本机传 -1 一个字都不画**（`kid_panel.py` 头注第 1 条）。
  名字行一直传显式长度（`kd_nmlen`）所以还在，台词行 / 提示行没了。
- 修：加两个「数到 NUL」循环 `kd_line_len` / `kd_hint_len`，以行宽 24 为界，把数出的 `ecx` 显式传给 TextOutA。
- 通法：**池格式与 `cbString` 必须成套** —— `[len][GBK][NUL]` 池 ⇒ 读 `row[0]` 当长度；
  `[GBK][NUL][pad]` 池 ⇒ **自己数到 NUL**。两套混用必出事。

### ④ 顺带：首屏空名单改成明说
串池加第 27 条「此城还没有可培养的孩子」（`MS_NONE`）。原来静默 return，玩家以为 MOD 坏。
**翻页过头（`start > 0`）仍静默**，避免按「下一页」到底时反复弹窗。

### 新增防御
- `kid_panel.selfcheck_panel`：`and ecx,0xff` == **0**；`push -1` == **0**；
  `cmp byte ptr [edi+ecx],0` == **2**；`cmp ecx,行宽` == **2**。
- `child_menu.selfcheck_foster`：对话框 8→**9**；`call child_pass` 早于 `call kd_show`；

- `verify_children.py`：C23z3g 改判据（不再期望 -1）；新增 **C23z3j / C23z3k / C23z3l**。
- **C23z8 判据换血**：四级弹窗不能按「紧邻前一条是 `push ecx`」认（实测四级收尾是
  `push eax` / `0xb` / `6` / `5`），改为按源码常量核

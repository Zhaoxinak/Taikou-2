## 1. 总体架构（✅ 已实证）

合战数据采用**「表之表」(table-of-tables) 注册表**模式，全部运行时从内存池 `0x524978` 分配并填充：

- **数据表目录基址 `0x517720`**：函数 `0x48bc00` 初始化时，逐个 `push <size>; mov ecx,0x524978; call 0x4eb5c0(malloc)` 分配缓冲，再把指针写入 `0x517720/0x517724/0x515c58/0x51e9c0/0x5205e4/0x517848/0x517838/0x518580/0x517cf8/0x51eb80…` 一串全局。
  - 首张表缓冲大小 `0xdf9c`(57244B) → 疑为整块合战场景态（含兵种/阵形/计略记录）。
  - 变体加载器 `0x43a460` 用 `base=[0x517720]; rec*96` 索引第一张 96B/条记录表 → **兵种/阵形/计略数据以 96B 记录形式存在该表**。
- **结论**：兵种/阵形/计略的**真实数值表不在 EXE 静态段**（0x517720/0x513a78/0x512f10 在静态映像里全为 0），而是**开局/进战时从合战地图文件（`HKMAPNEW.LZW`/`HJMAPDAT.DAT`）载入 `0x524978` 池后填充**。

## 2. 战图文件与缓冲（✅ 已实证）

- 地图文件名串 `@0x503700` = `"C:HKMAPNEW.LZW"`（✅ 确认）。
- 三段战图缓冲（来自 `0x43a580` 的 `push 0xb4/0x2f8/0x2f8`）：
  - A 头 `0x512e58` = 180B（= 20×9 宏观网格，stride 20）
  - B 地形 `0x512868` = 760B（= 40×19 半字节网格）
  - C 部署 `0x512b60` = 760B（= 40×19 ASCII 单位布阵）
- 解码/布阵函数集中在 `0x438000–0x439700`（`0x438fa0`/`0x438fc0` 部署解密器特判 ASCII 集 `{'/','1','7','9'}` 与 `{'+','-','3','5'}` 分左右两军；字符→精灵查表 `0x512f10`）。

### HJMAPDAT.DAT 实锤统计（38 张 × 1700B = 64600B）
- **地形类型 0–15 全部使用**，频率：
  - 0:38.9% 5:12.8% 4:9.8% 2:7.7% 3:6.6% 7:6.2% 1:4.6% 8:3.9% 6:2.4% 9:1.3% 10:1.1% 11:1.0% 13:1.8% 14:0.7% 12:0.7% 15:0.5%

## 3. 合战变体选择（✅ 已实证，公式完整）

函数 `0x43a460`（含 `0x43a4a6–0x43a4df`）：

```
tier = 0
for i in 0..9:
    if unit_byte <= TIER_THR[i]: tier = i; break   # TIER_THR @ 0x503740 (10 u8)
variant = rand() % TIER_RND[tier] + TIER_BASE[tier] # TIER_RND @ 0x503760, TIER_BASE @ 0x503750
offset  = variant * 68                              # variant*17*4
# 再用 offset 从 0x5036f0 资源指针解压对应战图变体
```
- `0x503740` = [13,17,21,25,29,33,36,40,70,80]（10 级阈值，单位强度字节比对）
- `0x503750` = [0,15,17,18,19,23,24,25,26,36]（每级基础偏移）
- `0x503760` = [15,2,1,1,4,1,1,1,10,2]（每级 rand()%n 的 n）

## 4. 八方向偏移表（✅ 已实证）

`@0x503710`：步长 4 的并行 word 表（取 +0/+2），值含 `0xffff=-1`，为 **8 方向 (dx,dy)** 偏移，供战场寻路/移动：
```
(0,-1)(1,0)(1,1)(0,1)(-1,1)(-1,0)(0,-1)(1,-1) ...（12 项候选，含 4 向+8 向变体）
```

## 5. 地形属性表（🔶 访问器已定位，内容运行时填充）

- 访问器 `0x43e820`：`index*5 + 0x513a78`，`index<0xf` → **地形属性表 @ 0x513a78，每记录 5 字节，约 15–16 项**。
- `0x43e8b0`：扫描 15 项（每项 +5），`byte[0]==0xff` 记为空 → **byte[0] 为地形 id/类型，0xff=未用**。
- 生成器 `0x43a580` 从 `0x43e820` 读 16 项填入 5 字节结构：`b0,b1,b2,b3,b4`（b4 经 `&0xf8` 掩码）。
- **静态映像中 0x513a78 全 0** → 内容由战图文件载入（见 §1）。

## 6. 部署字符→精灵表（🔶 访问器已定位，内容运行时填充）

- `@0x512f10`：20 字节表（`0x43a580` 用 `push 0x14; push 0x512f10` 建立）。
- 部署解密器 `0x438fa0/0x438fc0` 特判 ASCII 集 `{'/','1','7','9'}`（左军）与 `{'+','-','3','5'}`（右军），其余字符经 `0x512f10` 映射为精灵。
- 静态映像全 0 → 运行时从战图文件填充。

## 8. 兵种/阵形/计略名称归属（✅ 重要纠正）

- EXE 名表 `@0x506ca8`（370 条，GBK 变长 null 结尾）：**0–48 国名 / 49–291 城·町名 / 292–369 = 城(294–301:饫肥/鹿儿岛/…/大阪)+NPC与官职(302–369:大商人/茶道大师/洋枪铸造/步兵头/队长/侍大将/家老/大名…)**。

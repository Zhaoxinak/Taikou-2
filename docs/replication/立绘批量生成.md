## 续跑流程（每个武将 3 步）

### ① 取提示词
```bash
python tools/gen_portrait_prompts.py --top 5      # 看最高优先级 5 条
```
台账 `items[]` 每条含 `id / name / prompt / out_file / status`，取 `status=="pending"` 的。

### ② 调 ImageGen 生成原图
```
ImageGen(
  prompt       = <台账里的 prompt 原文>,
  size         = "1024x1280",          # 2x，缩放后正好 512×640
  background   = "transparent",
  output_dir   = "<工程根>/_portrait_raw/<id>"   # ★ 按 id 分目录，防对应错乱
)
```
单张约 5–10 积分。**生成前先问用户剩余额度**。

### ③ 缩放落地
```bash
python3 tools/finalize_portraits.py      # 处理 _portrait_raw/ 下全部（本机 Mac 已装 Pillow 12.3.0）
```
然后重跑 ① 刷新台账（已存在的自动标记 done），并把新图 + 台账 + 进度文件一起 commit/push。

## ⚠️ 硬规则（踩过坑的）

| 规则 | 原因 |
|---|---|
| 文件名必须是 `{id}_{姓名}.png` | `asset_loader.gd` 按此命名三级回退加载。`portrait_prompts.json` 里的 `full_XXXX.png`/`assets/gfx/` 写法**已过时** |
| 目标尺寸 512×640 | `AssetSpec.gd: PORTRAIT_SIZE`。必须缩放后入库，否则 695 张约 1GB |
| 国名走 `city → castle.province` | `officer["province"]` 字段与国表索引**对不上**（织田信长会解成骏河）。`gen_portrait_prompts.py` 已处理，勿改回 |
| 水印去不掉 | 右下角「AI生成 WORKBUDDY」是平台强制的 AI 内容合规标识，`footnote:""` 实测无效，**勿尝试裁剪去除** |
| 背景实际不透明 | `transparent` 参数不生效，模型会画完整场景背景——与原版立绘一致，**可接受，勿反复重试** |
| 提示词绝不写姓名/国名 | 模型会把汉字画成画面文字，一律用英文特征描述 |
| 暂存目录 `_portrait_raw/` | 已 gitignore；落地成功后可清空对应 id 子目录 |
| 进度文件 `portrait_v3_progress.json` | 每批落地后追加本批 id 到 `v31_done`，换 AI/断线靠它续跑 |

## 风格统一规范 v3.3（2026-09-10 用户逐项拍板后固化 · 唯一现行标准）

**用户验收链**：v2 HD-2D 暖黄散景（风格不统一被否）→ v3 写实（太像真人被否）→ v3.1 轻卡通（太卡通被否）→ v3.2 克制写实（太像真人被否）→ **v3.3 半写实手绘游戏感（用户认可"信长这种风格很好"）**。

### 1. 画风（v3.3 提示词模板，已写入 `gen_portrait_prompts.py::build_prompt`）

```
semi-realistic painted game-art portrait in classic Japanese strategy game style,
gentle stylized rendering with slight anime-inspired charm,
refined stylized eyes, clean crisp contours,
clean solid {bg} gradient background,
... balanced vivid historical colors, soft studio lighting,
dignified composition, no text, no letters, no kanji
```

- 介于写实与卡通之间，**稍微一丢丢卡通**：有手绘插画感（非照片感）、五官风格化不夸张、线条利落不过粗、配色明快但有历史厚重感。
- 纯色渐变背景，**永不写姓名/国名**（防汉字上画面）。

### 2. 史实样貌（`HISTORICAL_FACTS` 表，覆盖 200+ 知名武将）

### 3. 史实发型（统一标准）

- **月代头**（前额剃光 + 后脑发髻）是战国武士主流，prompt 必写 `traditional samurai topknot with shaved forehead (sakayaki)`；**发髻必须画明显**，防止被误看成秃头。
- 特殊人群例外：公卿（今川义元=公卿冠）、僧侣（显如=剃度）、美少年（森兰丸）、老者按史实。

### 4. 风化粗粝感（通用武将统一）

- 所有非知名武将统一加 `weathered campaign-worn skin`——久经战阵的沧桑质感，像"那个年代的人"，避免精致偶像脸。
- 知名武将走专属特征（森兰丸等特殊人设不受影响）。

### 5. 身份感（按职级区分，`RANK_DESC` 表）

| 职级 | 描述要点 |
|---|---|
| 大名 | `daimyo warlord, {色} lacquered armor with gold accents, ornate battle surcoat (jinbaori) over the armor` + 军配扇等威仪配饰 |
| 家老 | 正式甲胄，老练稳重 |
| 家臣 | 正式甲胄 |
| 组头/足轻头/足轻组头 | 轻甲/实用甲 |
| 无（浪人） | 旧甲旅行装 |

### 6. 家徽（`FAMILY_CRESTS` 表，全部武将上甲）

- 史实家徽（60+ 家族收录）：织田木瓜、武田菱、上杉竹雀、伊达三引両、北条三鱗、今川赤鳥、毛利一文字三星、島津十字、長宗我部七割引両、大友杏葉、三好三柏、齋藤二頭波、浅井花菱、朝倉木瓜、徳川三叶葵、真田六文銭、前田梅鉢、井伊井桁、蒲生茗荷、佐竹月星、最上三引両、明智桔梗等。
- 未收录家族：通用 `a traditional Japanese family crest emblem`，保证人人有家徽元素。
- 写法固定：`{crest} emblazoned on the chest armor`。

### 7. 配色（`FAMILY_COLORS` 表 + `PALETTE_POOL` 10 色池）

- 家族配色表覆盖 100+ 姓氏（织田黑红深绯、武田深红、上杉白淡灰蓝、伊达黑金深靛…），无名武将按 `id % 10` 哈希分配色板池。

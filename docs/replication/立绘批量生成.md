## 续跑流程（每个武将 3 步）

### ① 取提示词
```bash
python tools/gen_portrait_prompts.py --top 5      # 看最高优先级 5 条
```
台账 `items[]` 每条含 `id / name / prompt / out_file / status`，取 `status=="pending"` 的。

### ② 调 ImageGen 生成原图
```
ImageGen(
  prompt       = <台账里的 prompt 原文>,
  size         = "1024x1280",          # 2x，缩放后正好 512×640
  background   = "transparent",
  output_dir   = "<工程根>/_portrait_raw/<id>"   # ★ 按 id 分目录，防对应错乱
)
```
单张约 5–10 积分。**生成前先问用户剩余额度**。

### ③ 缩放落地
```bash
"C:/Users/Administrator/AppData/Local/Programs/Python/Python312/python.exe" \
    tools/finalize_portraits.py          # 处理 _portrait_raw/ 下全部
# 注意必须用系统 Python 3.12（有 Pillow）；托管 3.13 无 Pillow
```
然后重跑 ① 刷新台账（已存在的自动标记 done），并把新图 + 台账一起 commit/push。

## ⚠️ 硬规则（踩过坑的）

| 规则 | 原因 |
|---|---|
| 文件名必须是 `{id}.png` | `asset_loader.gd` 按 `res://assets/sprites/portraits/%d.png` 加载。`portrait_prompts.json` 里的 `full_XXXX.png`/`assets/gfx/` 写法**已过时** |
| 目标尺寸 512×640 | `AssetSpec.gd: PORTRAIT_SIZE`。必须缩放后入库，否则 695 张约 1GB |
| 国名走 `city → castle.province` | `officer["province"]` 字段与国表索引**对不上**（织田信长会解成骏河）。`gen_portrait_prompts.py` 已处理，勿改回 |
| 水印去不掉 | 右下角「AI生成 WORKBUDDY」是平台强制的 AI 内容合规标识，`footnote:""` 实测无效，**勿尝试裁剪去除** |
| 背景实际不透明 | `transparent` 参数不生效，模型会画完整场景背景——与原版立绘一致，**可接受，勿反复重试** |
| 暂存目录 `_portrait_raw/` | 已 gitignore；落地成功后可清空对应 id 子目录 |

## 风格统一规范 v2（2026-09-10 审查后固化）

**审查结论**：205 张中 16 张风格离群（偏冷色相 / 低饱和发灰 / 过暗 / 背景具象化 / 过亮过艳），已全部重绘并通过「HSV/亮度像素统计」复检，不再出现在离群名单。

**v2 提示词模板规则（已写入 gen_portrait_prompts.py，后续生成自动生效）**：
1. **移除 `clan of X` 段** —— 模型会把国名画成铠甲/背景上的汉字文字，一律删。
2. **追加统一风格段**：`warm amber gradient background, soft out-of-focus bokeh glow, no text, no kanji, no letters on armor or background`。
3. **禁止追加 `bright well-lit` / `vivid saturated colors`** —— 实测会导致画面过亮过艳（亮度 92–107 vs 主流中位 62），需再后处理压回调；正常生成不需要这两词。
4. 若个别图仍出现偏冷/偏暗/低饱和，优先用 **Pillow 后处理**（ImageEnhance.Brightness/Color，目标 lum≈64、s≈152）归位，不必重绘；色相偏冷无法后处理时才重绘。

**落地管线**：ImageGen(1024×1280) → `_portrait_raw/{id}/1.png` → `finalize_portraits.py`（512×640）→ 台账自动标记 done。

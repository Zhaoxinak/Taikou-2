# 大地图复刻笔记（world map replication notes）

## 坐标系统（数据层）
- 源数据：`scripts/castle_geo.json`（200 城史实经纬度，逐城对照 `data/castles.json` 权威名）。
- 投影：`scripts/gen_castle_map.py` v3 等距线性投影
  - lon∈[128.6, 142.2]，lat∈[41.7, 30.8] → 48×36 网格
  - 同格冲突用确定性亚格微偏移（hash ±0.45 cell，同 id 重跑稳定）
- 输出：`data/castle_map.json`（{id, x, y, has_town}，has_town = 92 町城）。
- 布局验证：东北（三户 44.2,3.9）右上 / 九州（鹿儿岛 6.7,32.4）左下 /
  四国（浦户）右下 / 京畿（二条 24.7,21.5）中央。ASCII 布局检查通过。
- 为什么弃用 TOWNPOS.DAT：二进制 16 字节/行含大量哨兵值（0xFF、(47,31)×6 等），
  92 城经纬度线性回归彻底失败（x 残差 RMSE 13.52 / y 8.63，无地理形状）。

## 移动机制（复刻原版）
原版依据（atwiki gcmatome / 太阁2 攻略手册 / ali213 攻略）：
- 移动方式两种：鼠标点位置 / 指定城町自动移动；自动移动"不走最短路径"是常态
- 四国・九州须经港町坐船；手册推荐路线 堺→鸣门→今治→小仓/府内 5 日到九州
- 每段航路 ≤2 日可免费搭船；连续坐船体力最低降到 20（不再降）
- 接近目的地出现"是否进入"询问；移动推进时间（"移動だけでも時間が進む"）

本复刻实现：
- `src/core/world_map.gd`（纯逻辑）：
  - STEP=1.0（逐格）、ENTER_DIST=1.6（相邻格即判进入）、MOVE_DAYS_PER_CELL=1.0
  - `move_towards`（朝目标走一步）、`path_cells`（直线格点路径）、`travel_days`
- `src/core/game_state.gd`：
  - `move_player(dx,dy)`：方向键逐格，每格推进 1 天
  - `move_player_towards(target)`：点击自动移动，每步 1 格推进 1 天
  - `travel_by_sea(to_id)`：坐船，消耗航路天数 + 体力压至 20（SEA_STAMINA_FLOOR）
  - `nearest_port()`：距离 ≤1.5 格的最近港町（京畿城密，用距离而非最近城判定）
- `src/ui/world_screen.gd`：
  - 鼠标左键点击地图 → 自动移动（MOVE_TICK=0.25s/格）；Esc 停止
  - 方向键/WASD 逐格；接近城（≤ENTER_DIST）高亮 + Enter 进入（城下町）
  - 在港町按 B 打开坐船菜单（可达港 + 天数）→ Enter 乘船
  - HUD：年/月/日/所在/体力
- 背景：`src/ui/japan_map.gd` 日本列岛简化海岸线多边形（本州/九州/四国/佐渡），
  与城堡同投影；环沿完整海岸线绕行保证三角剖分不自交。

## 航线（data/sea_routes.json，26 条双向）
- 濑户内（手册主线）：大坂(堺)→德岛(鸣门)→伊予(今治)→小仓→府内
- 补充：高松/冈山/三田尻/下关、日本海（敦贺→富山→新潟→酒田→八户）、
  太平洋（堺→津→沼津→江户→八户）、九州西岸（下关→平户→鹿儿岛→府内）
- 港町以邻近城堡代表示港：堺=大坂124、鸣门=德岛160、今治=伊予168
- loader 自动双向展开为 {from_id: [{to, days}]}
